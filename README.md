# 照片商品定位

安卓单机应用，使用实拍货架照片与商品标记来找货。当前版本 0.1.14，是供实际货架试用的首版。

## 0.1.14 商品资料搜索、筛选与排序

商品资料列表新增型号包含搜索（忽略大小写）、价格筛选及型号/价格/位置数量的升降序排序，默认保持原有顺序。价格筛选始终列出全部商品的不同价格，不受搜索影响；数值等价的价格如 9 与 9.00 合并为一个选项，另有“全部价格”和“未填写价格”。数值价格从低到高排列，原有“面议”等非数值内容仍可筛选。按价格排序时未填写价格始终最后。

显示符合条件数量/总数；全选仅选择当前结果，搜索、筛选或排序变化时清空勾选，防止删除隐藏商品。列表操作不改动商品、标记和照片，关闭重开商品资料时恢复默认条件。

统一显示设置新增默认开启的“商品资料搜索、筛选与排序”总开关。关闭后隐藏控件并显示全部商品与原有顺序。开关随资料保存及完整备份恢复，旧资料默认开启。

验证：20 项数据测试及四组浏览器交互回归通过，覆盖组合筛选、价格去重、全选/批量删除范围、取消/撤销、修改价格后选项更新、开关重启/恢复，并检查原有图片、批注、导航和删除确认。APK 构建与签名校验通过。本版未进行模拟器或实体手机验收。

## 0.1.13 删除确认总开关

管理 → 统一显示设置新增“删除前确认”，默认开启。统一控制照片、商品（含批量删除）、位置标记、商品附图、画笔与文本框：开启时展示删除范围并确认，关闭时直接执行；批量删除仅确认一次。删除完成不再显示结果提示，保存失败仍会报告错误。

取消确认或按安卓返回键会保留当前编辑页与尚未保存的内容。附图删除仍先作用于编辑草稿，保存后生效；其他删除保留原有撤销规则。开关随资料保存和完整备份恢复，没有此设置的旧备份默认开启。

17 项数据测试、原有与新增界面回归通过，覆盖七类删除入口在开启/关闭时的确认、取消、关联清理、撤销、无结果提示，以及开关重启/恢复。APK 构建与签名校验通过。新增安卓返回键取消与开关完整备份检查已编译，但本次模拟器持续离线，未获得运行结果；未进行实体手机验证。

## 0.1.12 价格导入、位置跳转与照片批注

- 管理 → 从表格导入价格：在手机选择未加密的 `.xlsx`，选择工作表、表头行、型号列和价格列。默认识别型号与第一列价格，也可选择“价格2”等其他列。先预览覆盖范围，确认后一次性更新，可撤销/重做。
- 型号按完整文本匹配，忽略大小写及两端空格；不会拆分同一单元格中的多个词，不改变现有型号。对应的全部商品资料价格更新，同型号位置共用。未匹配商品、空白/无效/负数价格保持不变；零价格有效。重复型号不同价格会列出冲突并跳过，同值重复可正常导入。公式、日期、百分比和错误单元格跳过，公式需先在表格软件中转为值。型号纯数字按整数读取，纯零格式（如 00000）保留前导零。
- 商品管理详情与图上标记详情均列出商品的全部位置，点击即可切换照片、居中并高亮目标。
- 搜索新增上/下目标按钮与目标计数。每次只定位一个目标，同图从左到右、同横坐标从上到下，之后按照片顺序跨图切换；首尾禁用对应按钮，保留原照片切换按钮。
- 定位始终把目标标记放在画布中心。取居中条件下铺满所需的最小比例，最多放大到普通铺满比例的 1.5 倍；靠边目标允许留白，避免过度裁掉照片。
- 编辑模式新增画笔、文字、选择/移动、颜色/大小。单指绘画，双指缩放/平移；进入双指操作时丢弃尚未完成的笔画。文字支持多行、颜色、字号、移动及删除；画笔支持颜色、粗细、移动和删除。点击批注可修改，保存后拖动选中的批注；撤销/重做适用于批注。
- 批注使用照片坐标保存，随图移动/缩放；完整备份及恢复包含画笔与文字，旧备份没有批注也能读取。表格只读，不复制进商品备份。

验证：16 项数据测试、17 项 XLSX 读取检查（包含提供的示例文件）、原有与新增浏览器交互回归通过；Android 模拟器 34 项检查通过，包含 5 项 Excel 文件读取/回调/取消/损坏处理，以及 2 项批注完整备份恢复检查。本机 APK 构建和签名校验通过。未进行实体手机验收。文件读取上限为 20 MB、32 个工作表、每表 50000 行/256 列、共 250000 个单元格；过大表格请拆分。当前不支持旧版 `.xls`。

## 0.1.11 信息跟随标记缩放

“管理 → 统一显示设置”新增默认开启的“信息跟随标记缩放”。开启后，信息固定在标记右上方，字号、内边距和与标记的间距一起随照片缩放，不自动避让或贴边挪动。文字大小以本次打开照片时初始铺满屏幕的比例为基准。关闭后恢复固定屏幕字号及自动避让。开关随资料保存、完整备份和恢复；没有此设置的旧资料默认开启。

12 项数据测试及浏览器交互回归通过，覆盖开关重启/恢复、同位置标签不避让、缩放比例、平移、标记越过边缘时可见标签保留，以及关闭后恢复固定字号与避让。本机 APK 构建及签名验证通过；本版未进行 Android 模拟器或实体手机验收。

## 0.1.10 商品附图拍照添加

添加、编辑标记及商品资料的“商品图片”区域新增“拍照添加”，保留“相册添加（可多选）”。每次确认拍照后追加一张图片，可反复点击继续拍摄。同型号共用，保存后进入完整备份，恢复时还原关联及图片。取消拍摄不改变附图；无相机或照片读取失败时显示提示并恢复入口。

调用系统相机保存完整照片到受临时授权保护的应用缓存文件，导入应用私有图片目录后撤销授权并清理拍照临时文件。使用现有图片导入的方向校正和尺寸控制，不依赖相册原图。拍照返回到编辑界面后仍需点击“保存”。

验证：11 项数据测试、浏览器交互测试通过；Android 模拟器 27 项检查通过，包含拍照输出读取、取消、缺失文件处理、备份恢复及真实触摸回归。已修正原生测试中软键盘和底部工具遮挡坐标的问题。APK 本机构建及签名校验通过；尚未在实体手机验证第三方相机界面。

## 0.1.8 商品多张附图

添加、编辑标记和商品资料时可以选择多张图片，保存后同型号的全部位置共用。先添加图片再输入新型号也会保留图片；切换到其他现有型号时显示该型号的图片，避免串图。标记详情和编辑界面可点缩略图查看大图。删除附图需确认，保存前取消编辑不改变资料；保存后的更改和商品删除可通过撤销还原。

图片导入为应用内独立副本，纠正方向，最长边超过 6000 像素时缩小，保存为高质量 JPEG；相册原图删除不影响附图。取消或部分导入失败会结束等待状态，成功导入的图片仍可保存。

完整备份收录货架照片及当前商品引用的所有附图，去重打包；恢复前校验文件路径、图片是否存在及能否读取，缺失或损坏则拒绝替换当前资料。恢复前自动备份也包含附图。兼容无附图的旧备份。删除或取消添加的图片文件暂留应用私有目录，与现有照片保留机制一致，便于撤销；不再关联的图片不进入完整备份。

验证：11 项数据测试、浏览器交互回归及新增附图测试通过；Android 模拟器 14 项检查覆盖多图导入、独立副本、备份清单、恢复关联与文件、恢复前自动备份、缺失/损坏拒绝、旧备份和取消选择。本机构建和签名校验通过。未做实体手机相册选择器验收。

## 安装与使用

0.1.1 更新：照片画布覆盖屏幕顶端到底端，标题区域不再占位，搜索和操作按钮改为悬浮。点“隐藏工具”可收起控件。默认按比例铺满，左右超出的内容可拖动查看；点“铺满”恢复。仍保留手动缩小和多目标自动取景，避免漏掉命中商品。安卓系统栏默认收起，从屏幕边缘滑动可以临时显示。

安装交付的 `photo-marker-0.1.10.apk`（安卓安装包），要求安卓 9 或以上。此包使用本项目测试签名，后续更新须保持签名一致。不要通过卸载来更新，卸载会删除应用私有资料。

1. 点击“导入货架照片”，选择图片并命名。应用保存独立副本，相册原图删除不影响使用。导入会纠正照片方向，最长边超过 6000 像素时缩小至 6000 像素，并以高质量保存。
2. 点击“进入编辑”→“连续标记”，放大并平移到商品，点按添加标记。型号未填写时自动编号，价格可空，自定义属性按名称和内容录入。
3. 可选择圆点、矩形框、椭圆圈，调整宽高和角度。保存后拖动选中标记调整位置；双指缩放，拖动空白平移。新增不复制上次型号或价格，只沿用样式和大小。
4. 点击“完成编辑”。输入部分型号，按包含关系实时定位。多图命中用上下箭头循环切换；同图多标记同时突出。清空搜索恢复照片浏览。
5. “管理”→“统一显示设置”选择型号、价格、扩展属性与字号。字号不随照片缩放。标签自动尝试避让，密集区域仍可放大查看。
6. 点按标记查看资料。修改同型号价格会同步；修改标记型号只改变当前关联。改成已有型号自动带出资料，改成新型号或留空自动编号时清空价格和属性，以免带错资料。
7. 删除最后一个位置标记时同步删除商品。商品资料可编辑价格与属性，也可多选批量删除；删除商品会同时删除全部关联位置标记。

## 备份与恢复

“管理”→“导出完整备份”，选择保存位置。一个压缩文件包含当前货架照片、商品附图、商品资料、标记及显示设置。请另存一份到手机以外的位置。

恢复会替换全部数据。先校验格式、照片和关联，再生成恢复前自动备份，最后替换数据。通过“导出恢复前的自动备份”可另存该文件。仅保留最近一次恢复前备份。异常中断时会优先恢复原数据目录。单次恢复解压数据上限为 2 GiB（吉比字节），资料文件上限为 20 MiB（兆比字节）。

编辑后自动保存，数据文件采用原子写入。撤销重做最多保存本次运行的 40 步；重新启动或恢复备份后清空历史。删除照片后副本暂留应用私有目录，便于撤销，导出备份仅收录当前使用的照片。

## 实现与构建

原生安卓外壳搭配本机网页画布界面；无账号，无服务器，无网络权限。照片坐标归一化存储，框和圈随图缩放，文字默认跟随照片缩放，可在统一显示设置中切换为固定屏幕字号。

常规构建：Gradle（构建工具）8.10.2、安卓构建插件 8.8.0、Java（编程语言运行环境）17 或以上、安卓开发工具包平台 35。

```powershell
gradle assembleDebug
```

无依赖下载的本地构建：设置 JAVA_HOME（运行环境目录变量），然后执行：

```powershell
./build-local.ps1 -SdkPath '你的安卓开发工具包路径'
```

需要平台 35 和构建工具 35.0.0。脚本生成并复用项目内的测试密钥，密钥不进入版本库，须在本机保留以支持覆盖更新。构建产物位于 `app/build/local/`（应用构建输出目录）。

测试：

```powershell
node --test tests/model.test.js
node tests/ui.cjs
node tests/features-ui.cjs
node tests/deletion-ui.cjs
node tests/product-list-ui.cjs
```

第一项为数据行为测试；第二项为浏览器交互测试，需 Playwright（浏览器自动化测试工具），当前脚本使用制作环境中的浏览器路径。
