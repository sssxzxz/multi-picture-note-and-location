# 照片商品定位

安卓单机应用，使用实拍货架照片与商品标记来找货。当前版本 0.1.9，是供实际货架试用的首版。

## 0.1.9 标记点击穿透修复

标记编辑、详情和新增标记改为在完整点击事件中打开弹窗，避免手指抬起后生成的点击误触刚弹出的表单。保留正常单击编辑、拖动标记、双指缩放及弹窗内的新点击。

11 项数据测试和浏览器交互回归通过；新增重叠位置连续触摸、释放时序、弹窗后续点击和拖动检查。同一触摸回归在 0.1.8 原代码上复现误触“添加属性”，修复后通过。本机安装包构建及签名校验通过。本次 Android 模拟器多次冷启动未能及时就绪，新增原生触摸检查尚未得到通过结果；未进行实体手机验证。

## 0.1.8 商品多张附图

添加、编辑标记和商品资料时可以选择多张图片，保存后同型号的全部位置共用。先添加图片再输入新型号也会保留图片；切换到其他现有型号时显示该型号的图片，避免串图。标记详情和编辑界面可点缩略图查看大图。删除附图需确认，保存前取消编辑不改变资料；保存后的更改和商品删除可通过撤销还原。

图片导入为应用内独立副本，纠正方向，最长边超过 6000 像素时缩小，保存为高质量 JPEG；相册原图删除不影响附图。取消或部分导入失败会结束等待状态，成功导入的图片仍可保存。

完整备份收录货架照片及当前商品引用的所有附图，去重打包；恢复前校验文件路径、图片是否存在及能否读取，缺失或损坏则拒绝替换当前资料。恢复前自动备份也包含附图。兼容无附图的旧备份。删除或取消添加的图片文件暂留应用私有目录，与现有照片保留机制一致，便于撤销；不再关联的图片不进入完整备份。

验证：11 项数据测试、浏览器交互回归及新增附图测试通过；Android 模拟器 14 项检查覆盖多图导入、独立副本、备份清单、恢复关联与文件、恢复前自动备份、缺失/损坏拒绝、旧备份和取消选择。本机构建和签名校验通过。未做实体手机相册选择器验收。

## 0.1.7 恢复原有删除交互

撤销 0.1.5 的修改，恢复 0.1.4 的删除交互：位置标记直接删除，照片删除保留简短确认，商品删除保留原有确认和结果提示。保留撤销、关联清理，以及 0.1.6 的搜索不区分大小写。

## 0.1.6 搜索不区分大小写

型号包含搜索忽略英文字母大小写，照片筛选、自动定位和标记高亮保持一致。型号原文和商品关联规则不变。

## 0.1.5 删除确认（已在 0.1.7 撤销）

删除位置标记前提示型号、照片，以及是否同时删除最后位置对应的商品资料。删除照片前提示照片名、位置标记数与将清理的商品数。单个和批量商品删除继续显示商品及关联标记数。所有删除统一使用“取消”和“确认删除”，不显示删除成功提示，保留撤销功能。

## 0.1.4 商品批量删除与位置约束

- 管理 → 统一显示设置：新增“移动或缩放照片时自动隐藏工具”开关，默认开启，保存后持续生效；关闭后仍可手动隐藏工具。
- 商品资料支持多选、全选、取消全选和批量删除。删除前显示商品数与位置标记数；所有商品均可删除，其在全部照片中的标记同步删除，照片保留，可撤销。
- 新建或编辑标记时，空型号或纯空格自动生成“自动编号0001”等唯一型号，避开已有型号，编号进度随备份保存。
- 每个商品必须有位置。删除最后一个标记、删除照片或更改型号后，自动清理不再有位置的商品。
- 打开旧资料或恢复旧备份时，清理无位置商品，并为已有位置的空型号补编号。

验证：8 项数据测试及浏览器交互测试通过，本机 APK 构建与签名验证通过。尚未进行手机实机验证。

## 0.1.2 搜索铺满与信息清理

搜索跳转的缩放下限为铺满屏幕，自动平移限制在照片边缘内，避免跳转后露出背景。货架信息简化为照片名和张数，跟随搜索框实际高度定位，使用不透明底色。移除浏览状态和双指缩放等常驻操作提示。多目标相距过远时，优先铺满屏幕，视野外目标可通过平移查看。

## 0.1.3 移动照片自动隐藏工具

在搜索前后，拖动或双指缩放照片会自动收起工具。照片位置、当前搜索和标记资料保持不变；点击显示工具恢复。单击标记、编辑时拖动已选中的标记不触发自动隐藏。

## 安装与使用

0.1.1 更新：照片画布覆盖屏幕顶端到底端，标题区域不再占位，搜索和操作按钮改为悬浮。点“隐藏工具”可收起控件。默认按比例铺满，左右超出的内容可拖动查看；点“铺满”恢复。仍保留手动缩小和多目标自动取景，避免漏掉命中商品。安卓系统栏默认收起，从屏幕边缘滑动可以临时显示。

安装交付的 `photo-marker-0.1.9.apk`（安卓安装包），要求安卓 9 或以上。此包使用本项目测试签名，后续更新须保持签名一致。不要通过卸载来更新，卸载会删除应用私有资料。

1. 点击“导入货架照片”，选择图片并命名。应用保存独立副本，相册原图删除不影响使用。导入会纠正照片方向，最长边超过 6000 像素时缩小至 6000 像素，并以高质量保存。
2. 点击“进入编辑”→“连续标记”，放大并平移到商品，点按添加标记。型号未填写时自动编号，价格可空，自定义属性按名称和内容录入。
3. 可选择圆点、矩形框、椭圆圈，调整宽高和角度。保存后拖动选中标记调整位置；双指缩放，拖动空白平移。新增不复制上次型号或价格，只沿用样式和大小。
4. 点击“完成编辑”。输入部分型号，按包含关系实时定位。多图命中用上下箭头循环切换；同图多标记同时突出。清空搜索恢复照片浏览。
5. “管理”→“统一显示设置”选择型号、价格、扩展属性与字号。字号不随照片缩放。标签自动尝试避让，密集区域仍可放大查看。
6. 点按标记查看资料。修改同型号价格会同步；修改标记型号只改变当前关联。改成已有型号自动带出资料，改成新型号或留空自动编号时清空价格和属性，以免带错资料。
7. 删除最后一个位置标记时同步删除商品。商品资料可编辑价格与属性，也可多选批量删除；删除商品会同时删除全部关联位置标记。

## 备份与恢复

“管理”→“导出完整备份”，选择保存位置。一个压缩文件包含当前货架照片、商品附图、商品资料、标记及显示设置。请另存一份到手机以外的位置。

恢复会替换全部数据。先校验格式、照片和关联，再生成恢复前自动备份，最后替换数据。通过“导出恢复前的自动备份”可另存该文件。仅保留最近一次恢复前备份。异常中断时会优先恢复原数据目录。单次恢复解压数据上限为 2 GiB（吉比字节），资料文件上限为 20 MiB（兆比字节）。

编辑后自动保存，数据文件采用原子写入。撤销重做最多保存本次运行的 40 步；重新启动或恢复备份后清空历史。删除照片后副本暂留应用私有目录，便于撤销，导出备份仅收录当前使用的照片。

## 实现与构建

原生安卓外壳搭配本机网页画布界面；无账号，无服务器，无网络权限。照片坐标归一化存储，框和圈随图缩放，文字保持固定屏幕字号。

常规构建：Gradle（构建工具）8.10.2、安卓构建插件 8.8.0、Java（编程语言运行环境）17 或以上、安卓开发工具包平台 35。

```powershell
gradle assembleDebug
```

无依赖下载的本地构建：设置 JAVA_HOME（运行环境目录变量），然后执行：

```powershell
./build-local.ps1 -SdkPath '你的安卓开发工具包路径'
```

需要平台 35 和构建工具 35.0.0。脚本生成并复用项目内的测试密钥，密钥不进入版本库，须在本机保留以支持覆盖更新。构建产物位于 `app/build/local/`（应用构建输出目录）。

测试：

```powershell
node --test tests/model.test.js
node tests/ui.cjs
```

第一项为数据行为测试；第二项为浏览器交互测试，需 Playwright（浏览器自动化测试工具），当前脚本使用制作环境中的浏览器路径。

- 浏览器交互测试：每图 32 个标记、实时定位、上下切换、已有型号价格带出、价格保存、撤销重做、统一字号。
- 安卓源码编译、安装包生成、签名校验。
